# /pocket — 전체 UI/UX 디자인 리뷰

작성: 2026-06-08 · 4개 관점 종합(디자인 / 일반 사용자 / 장기 배당투자자 / QA) · 22개 스크린샷(라이트·다크 전 탭+시트) + 코드 기반.

전반적으로 **완성도 높은 미니멀 surface**다 — 타이포·여백·대비(AA)·iOS 시트/탭바 문법이 일관되고, 빈/로딩/에러 상태와 도넛 경계값 처리가 탄탄하며, 크래시·NaN·깨진 레이아웃(P0 결함)은 없다. 개선 여지는 대부분 **"숫자에 이름표가 없어서 오해를 부르는"** 데이터 라벨링과 **화면 간 일관성**, 그리고 **접근성**에 몰려 있다.

---

## P0 — 오해/오판을 부르는 것 (우선 수정 권장)

### 1. 홈(Dividends)의 D/W/M/Y 큰 숫자가 "실제로 받은 돈"처럼 읽힌다 ★최다 합의
- 현상: `M 65.24`를 보면 "이번 달 65.24달러 받음"으로 읽힘. 실제로는 연 추정(782.91)을 12로 나눈 **평균 run-rate(추정치)**. 진짜 받은 금액은 Activity→Received의 **176.98**(두 탭 건너편에 숨음). 홈엔 이게 추정/평균이라는 표시도, 통화기호도 없음.
- 누적 문제 3가지: ① 평균/추정이라는 라벨 없음 ② D/W/M/Y 글자에 범례 없음(Day/Week/Month/Year 추측) ③ 통화기호 없음(다른 곳은 USD/CAD 표기).
- 제안(빠른 수정): 숫자 블록 위/아래에 한 줄 캡션 복구 — 예 **"Estimated average · at current rate"**, 통화기호($) 추가. 군더더기 캡션을 덜어내며 이 한 줄까지 지운 게 과했음. (`pocket-hero.tsx`)

### 2. Trades "All" 합계가 의미 없는 숫자 (wrong number)
- 현상: `total = 수량 × 가격`이 **항상 양수**(SELL도 음수 아님). 필터 `All`에서 BUY+SELL+DIV를 모두 양수로 더해 "USD 27,800" 식으로 표기 → 순현금이 아니라 **총거래대금(gross turnover)**. 5천 매수 + 5천 매도 → "$10,000".
- 제안: 액션별 부호 처리해 순액으로 보이거나, 필터=All일 땐 헤더 합계를 숨기고 단일 액션에서만 표시. 최소한 "USD" 라벨이 순액처럼 안 읽히게. (`transaction-view.tsx:169-174`, `api/transactions/calendar/route.ts:26`)

## P1 — 가치/일관성 핵심 (높은 레버리지)

### 데이터 라벨링 · 신뢰
3. **Cash 탭이 "잔액/한도"처럼 읽힘.** 실제로는 기간 **기여금(gross deposits)**인데 "Cash" 탭 + 큰 "CAD C$8,869" + 명사 없는 행("TFSA(6263) C$5,718")이라 *계좌에 든 현금* 또는 *TFSA 납입한도*로 오해. 제안: 행/캡션에 명사 — "Contributions · gross deposits" 또는 "Cash balance" 중 실제 의미로 명시. 괄호 숫자(6263 등=계좌번호)도 "Cash account" 같은 단어 필요. (`cash-flow-view.tsx`)
4. **Charts 도넛 색이 스와이프 시 종목별로 뒤바뀜.** 색을 종목이 아니라 **순위 인덱스**로 배정(`pocket-donut.tsx:35,37`) → Dividend 도넛에선 QLD 노랑, Value 도넛에선 주황. "한 포트폴리오의 두 뷰" 모델이 깨짐. 제안: 보유 종목 합집합에서 **종목→색 고정 맵**을 한 번 만들어 두 도넛에 공유.
5. **Value 도넛 aria-label이 "Dividend distribution"으로 고정**(`pocket-donut.tsx:90`) → 스크린리더가 Value 페이지에서도 "Dividend" 읽음. `ariaLabel` prop 추가해 metric별 전달.
6. **도넛 팔레트의 빨강 슬라이스.** 금융 앱에서 빨강=손실/에러 시맨틱인데 순위로 일반 종목에 빨강이 배정됨(`chart-tokens.ts`). 빨강을 할당 램프에서 빼거나 코랄로.

### 일반 사용자 이해도 (최근 캡션 제거가 과했던 지점)
7. **Ex/Pay 배지에 범례 없음.** 일반 사용자는 "Ex"를 모름. 같은 배당이 EX·PAY 두 행으로 보여 두 번 받는 것처럼 오해. 제안: 필터를 "Ex-date / Pay-date"로 풀어쓰고 한 줄 범례("Ex = 이 날짜까지 보유해야 받음 · Pay = 입금일") 또는 "Cutoff/Paid"로.
8. **Net/Gross 설명 없음**(회계 용어). Settings 토글 밑에 한 줄: "Net = 원천징수 후 · Gross = 세전". (최근 제거된 그 캡션이 실제로 필요했던 케이스)
9. **추정 표시가 일부 행에만** — 상단 "🕐 estimated date" 범례와 떨어진 두 행만 시계. 금액도 추정인지 불명. 범례를 "🕐 = 아직 미확정 추정 날짜"로 명확히, 추정 금액도 동일 마크.

### 화면 간 일관성 (디자인)
10. **포트폴리오 피커 위치가 탭마다 다름** — Dividends/Charts는 우상단, Activity는 좌상단. 한 코너로 통일.
11. **Activity만 화면 타이틀(h1) 없음** — 다른 3탭은 큰 제목으로 시작. 통일(추가하거나 의도적으로 일관).
12. **시트 선택 표현이 두 언어** — Period 시트: 연도는 검정 **pill**, 기간은 회색 fill+**체크**. 하나로 통일. 포트폴리오 시트의 점(빈 링/회색/초록)도 의미 불명·2줄 행에서 수직정렬 안 맞음.
13. **Settings 포트폴리오 영역** — "All"은 맨 행(라디오링+쉐브론), 바로 아래 "Manage"는 채운 카드 → 인접한데 컨테이너 다름. 통일.

### 접근성 / 에러 복구 (QA)
14. **시트가 `aria-modal`인데 포커스 트랩·복귀·Escape 없음**(`period-picker.tsx:52`, `portfolio-picker.tsx:39`, `group-manager.tsx:225`). 키보드/SR 사용자가 배경으로 Tab 가능. 마운트 시 포커스 이동·Tab 트랩·Escape→닫기·언마운트 시 포커스 복귀.
15. **Activity 3개 모드에 Retry 없음**(`history-view.tsx:67` 등) — fetch 실패 시 모드 전환으로만 복구. Hero처럼 Retry 버튼.

### 도메인 (장기 배당투자자 — *제품 방향 결정 필요*)
16. **헤더 YIELD가 current yield**(run-rate ÷ 시가, `pocket-shell.tsx:96`). DGI 투자자에겐 **yield-on-cost**가 핵심. `avgCost`는 이미 스키마에 있음(`schema.prisma:49`). "2.07% now · 3.4% on cost" 식 한 줄 제안.
17. **커버드콜/ROC 분배금을 안정적 '배당'처럼 표기.** QQQI/JEPQ/GPIQ/QDVO는 옵션프리미엄·원금반환 성격인데 같은 run-rate·YIELD에 혼합. `confident`는 "기록 2개 이상"일 뿐 변동성 아님. 현재 이들이 income의 ~4%라 금액 오차는 작지만 프레이밍이 위험(yield trap). 제안: 분배형 ETF에 "DIST" 구분 표기, confidence를 분배 **변동성** 기준으로.
18. **변동 분배(SCHD)를 최근 1회×4로 연환산** — SCHD가 income의 90%라 가장 큰 금액 가정. TTM 실적 합으로 연환산 권장(받은 내역 이미 로드됨).

## P2 — 다듬기 / 추가 가치
- **배당 성장(YoY)·DRIP 누적이 어디에도 없음** (장기투자자 핵심이지만 데스크톱 도구가 담당 — /pocket엔 Received에 "2026 +X% vs 2025" 한 줄 정도가 가성비 최고). DRIP "올해 +N주 재투자"도 데이터 이미 있음.
- **TFSA/RRSP 납입한도** 맥락 부재(데스크톱 영역, 우선순위 낮음).
- **도넛 중앙 값 auto-fit 아님**(고정 28px, `pocket.css:1116`) — 7자리 시가총액이면 링 밖으로. Hero는 auto-fit 하는데 도넛은 안 함.
- **reduced-motion이 CSS만**, JS 페이저 애니메이션(`swipe-pager.tsx`)은 무시.
- **무음 FX fallback**(`?? 1.39`)을 Activity 모드들이 경고 없이 사용 — Hero처럼 "기본환율" 노트.
- **터치 타깃 <44px**: 닷(~19px), 칩(30px), 색 스와치(30px).
- **긴 티커가 고정 셀(54px) 넘침** — `overflow:hidden;text-overflow:ellipsis` 또는 유연 컬럼.
- **페이지 닷이 서브탭마다 의미 바뀜**(Upcoming=All/Ex/Pay 3개, 나머지=기간 6~7개) — 닷 개수가 3→7로 튀어 글리치처럼 보일 수 있음.
- **SELL 배지가 화면에서 가장 강함**(검정/흰 솔리드) — 의도면 OK, 아니면 톤다운.
- **Dividends 캡션 복구**(P0 #1과 동일 — 한 줄로 해결).
- **"Full year" vs 연도 칩** 구분에 작은 힌트("연도 → 기간 선택").

## 잘 되어 있는 부분 (QA 검증 완료)
빈/로딩/에러 상태 전부 **구분되는 친절한 카피**로 처리(보유 0 / 배당데이터 없음 / 그룹에 매칭 종목 없음 / 기간 거래 없음 / 연도 없음 등). 도넛 퇴화 케이스(빈/전부0/음수/단일100% 이음새/`<1%` 표기) 안전, yield 0-나눗셈 가드, **연도 전환 중 stale 기간목록 race 수정 확인**, 삭제된 그룹 id→All 폴백, 기간 페이저 desync 재정렬, 잘못된 날짜 문자열 폴백, fetch 취소 플래그. 라이트/다크 대비(AA) 양호.

2. **Trades "All" 합계 순액화 또는 숨김** (P0 #2) — wrong number 제거.

4. **Net/Gross · Ex/Pay 한 줄 범례 복구** (P1 #7,8) — 카피만.
